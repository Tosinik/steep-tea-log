B4 SCRIPT

Per-origin script — each tea in its own culture's characters

DECISION · catalog-sourced, never guessed

Not “a Japanese app” — each tea written as its own origin writes it: Chinese teas in Chinese characters (Traditional/Simplified per origin), Japanese in kanji/kana. Same three-tier pattern as the liquor swatch, off the v3.87 catalog's verified CJK names. Design owns the treatment; Code owns the data + read-path (flagged for hand-off). Hard rule: wrong characters are worse than none.
