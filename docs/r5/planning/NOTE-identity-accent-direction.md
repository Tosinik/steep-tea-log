# NOTE · Identity + Accent Direction (PARKED)

**Status:** direction decided, **PARKED** until the roadmap features land (smart-restock, guided mode,
the spine rollout, the security gate). This is an app-wide **token + layout** pass, and doing it before
those ship would mean re-skinning the new surfaces again. Revisit after the feature work.

## Decided
- **Accent → hōjicha `#A55A32`** (a red-brown roasted-tea amber). Chosen over roasted-oolong gold because
  it carries fill and text at one hex, and because it reads as "the colour in the cup," not a generic
  orange. Retunes the burnt amber-clay `#C17A3E` that currently carries status, stars, the ensō dot and
  the steep bar.
- **Green → the richer G2** (the yellow taken out of the current forest green). Cheapest change on the
  board; lifts every screen.
- **Journal lean (Lever B):** let the diary bones beat the generic-app bones. Set type + hairline rules
  for STRUCTURAL elements (lists, stat blocks, the greeting); keep ROUND for CALM elements (the timer, tea
  swatches, a single highlighted stat). Round stays where it soothes; structure moves to type.
- **Faint washi / laid-paper texture** on the cream ground so it reads as a page, not a flat background.
- **Keep the ensō ring** (semantic) and **keep the green month-slab as a landmark** — Design's finding: the
  slab tells you where the monthly entry is without reading, so the lean must not flatten it into another
  ruled line (the "middle version").
- **Insights ships the journal lean first** — its all-time block is already a ledger, so it's the cheapest
  place to prove Lever B.
